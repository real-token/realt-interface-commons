# 🗣️ Internationalisation (i18n)

RealT Commons intègre un système complet d'internationalisation basé sur i18next avec support pour le français, anglais et espagnol.

## 🌍 Langues supportées

- 🇫🇷 **Français** (fr) - Langue par défaut
- 🇬🇧 **Anglais** (en)
- 🇪🇸 **Espagnol** (es)

## ⚙️ Configuration de base

### Initialisation d'i18next

```typescript
import { initLanguage } from "@realtoken/realt-commons";
import { resources } from "./i18next/locales";

// Initialisation avec vos ressources personnalisées
export const i18n = initLanguage(resources);
```

## 🌐 Sélecteur de langue

### Composant sélecteur

```typescript
import { useTranslation } from "react-i18next";
import { Select } from "@mantine/core";

const LANGUAGES = [
  { value: "fr", label: "🇫🇷 Français" },
  { value: "en", label: "🇬🇧 English" },
  { value: "es", label: "🇪🇸 Español" },
];

function LanguageSelector() {
  const { i18n, t } = useTranslation();

  const handleLanguageChange = (language: string) => {
    i18n.changeLanguage(language);
    localStorage.setItem("realt-language", language);
  };

  return (
    <Select
      value={i18n.language}
      data={LANGUAGES}
      onChange={handleLanguageChange}
      placeholder={t("common.selectLanguage")}
    />
  );
}
```

### Hook personnalisé pour la langue

```typescript
import { useTranslation } from "react-i18next";
import { useCallback } from "react";

export function useLanguage() {
  const { i18n } = useTranslation();

  const changeLanguage = useCallback(
    (lng: string) => {
      i18n.changeLanguage(lng);
      localStorage.setItem("realt-language", lng);

      // Notification optionnelle
      console.log(`Langue changée vers: ${lng}`);
    },
    [i18n]
  );

  const getCurrentLanguage = useCallback(() => {
    return i18n.language;
  }, [i18n]);

  const getSupportedLanguages = useCallback(() => {
    return ["fr", "en", "es"];
  }, []);

  return {
    currentLanguage: i18n.language,
    changeLanguage,
    getCurrentLanguage,
    getSupportedLanguages,
    isLanguageSupported: (lng: string) => getSupportedLanguages().includes(lng),
  };
}
```

## 📱 Formatage et localisation

### Formatage des nombres et devises

```typescript
import { useTranslation } from "react-i18next";

function PriceDisplay({ amount, currency = "EUR" }) {
  const { i18n } = useTranslation();

  const formatCurrency = (value: number) => {
    return new Intl.NumberFormat(i18n.language, {
      style: "currency",
      currency: currency,
    }).format(value);
  };

  const formatNumber = (value: number) => {
    return new Intl.NumberFormat(i18n.language).format(value);
  };

  return (
    <div>
      <p>Prix : {formatCurrency(amount)}</p>
      <p>Nombre : {formatNumber(amount)}</p>
    </div>
  );
}
```

### Formatage des dates

```typescript
import { useTranslation } from "react-i18next";

function DateDisplay({ date }: { date: Date }) {
  const { i18n } = useTranslation();

  const formatDate = (date: Date) => {
    return new Intl.DateTimeFormat(i18n.language, {
      year: "numeric",
      month: "long",
      day: "numeric",
    }).format(date);
  };

  const formatDateTime = (date: Date) => {
    return new Intl.DateTimeFormat(i18n.language, {
      year: "numeric",
      month: "short",
      day: "numeric",
      hour: "2-digit",
      minute: "2-digit",
    }).format(date);
  };

  return (
    <div>
      <p>Date : {formatDate(date)}</p>
      <p>Date et heure : {formatDateTime(date)}</p>
    </div>
  );
}
```

## 💡 Bonnes pratiques

✅ **Organiser** les traductions par namespace/module
✅ **Utiliser** des clés descriptives (`user.welcome` vs `msg1`)
✅ **Éviter** les traductions trop longues dans le code
✅ **Tester** toutes les langues supportées
✅ **Gérer** les textes manquants avec des fallbacks
✅ **Utiliser** l'interpolation pour les données dynamiques
❌ **Éviter** les traductions hardcodées
❌ **Ne pas** oublier de traduire les messages d'erreur
❌ **Ne pas** imbriquer trop profondément les clés de traduction

## 🔧 Utilitaires i18n

### Validation des traductions

```typescript
function validateTranslations(resources: any) {
  const languages = Object.keys(resources);
  const baseKeys = getNestedKeys(resources[languages[0]]);

  languages.forEach((lang) => {
    const langKeys = getNestedKeys(resources[lang]);
    const missingKeys = baseKeys.filter((key) => !langKeys.includes(key));

    if (missingKeys.length > 0) {
      console.warn(`Clés manquantes pour ${lang}:`, missingKeys);
    }
  });
}

function getNestedKeys(obj: any, prefix = ""): string[] {
  return Object.keys(obj).reduce((keys: string[], key) => {
    const fullKey = prefix ? `${prefix}.${key}` : key;

    if (typeof obj[key] === "object" && obj[key] !== null) {
      keys.push(...getNestedKeys(obj[key], fullKey));
    } else {
      keys.push(fullKey);
    }

    return keys;
  }, []);
}
```
